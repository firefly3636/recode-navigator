============================================
  リコード法ナビゲーター デプロイ手順書
============================================

このフォルダには、アプリをインターネット上に公開するためのファイルが
すべて含まれています。以下のいずれかの方法でデプロイできます。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  方法1: ワンクリック自動デプロイ（推奨）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. GitHubアカウントを作成（未登録の場合）
   → https://github.com にアクセスし、無料アカウントを作成

2. deploy.bat をダブルクリック
   → ブラウザが開くので、表示されるコードを入力しGitHubにログイン
   → 自動的にリポジトリ作成・デプロイ・URL発行まで完了します


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  方法2: Netlify Drop（アカウント不要・最も簡単）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. ブラウザで https://app.netlify.com/drop を開く

2. この「recode-app-deploy」フォルダ全体を
   ブラウザの画面にドラッグ＆ドロップ

3. 数秒でデプロイ完了！URLが表示されます
   （例: https://random-name-12345.netlify.app）

※ アカウント登録なしで使えます
※ URLを永続化したい場合はNetlifyアカウント（無料）を作成してください
※ カスタムドメインも設定可能です


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  方法3: 手動デプロイ（GitHub Pages）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. https://github.com にログイン
2. 右上の「+」→「New repository」
3. Repository name: recode-navigator
4. 「Public」を選択 → 「Create repository」
5. 「uploading an existing file」リンクをクリック
6. このフォルダ内の全ファイルをドラッグ＆ドロップ
7. 「Commit changes」をクリック
8. Settings → Pages → Source を「Deploy from a branch」
9. Branch: main, Folder: / (root) → Save
10. 数分後にURLが表示されます
    （例: https://あなたのユーザー名.github.io/recode-navigator/）


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ファイル一覧
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

index.html     ... アプリ本体
manifest.json  ... PWA設定（スマホにインストール可能にする）
sw.js          ... Service Worker（オフライン対応）
icon-192.svg   ... アプリアイコン（小）
icon-512.svg   ... アプリアイコン（大）
favicon.svg    ... ブラウザタブのアイコン
deploy.bat     ... 自動デプロイスクリプト


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  PWA（Progressive Web App）について
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

デプロイ後、スマホやPCで以下のようにアプリとしてインストールできます：

【スマートフォン（iPhone/Android）】
1. Safari/Chromeでデプロイ先URLを開く
2. 「ホーム画面に追加」を選択
3. アプリアイコンがホーム画面に追加されます

【PC（Chrome/Edge）】
1. デプロイ先URLをChromeまたはEdgeで開く
2. アドレスバー右端のインストールアイコンをクリック
3. デスクトップアプリとして起動可能になります

※ オフラインでも使用可能です（Service Workerがキャッシュします）
